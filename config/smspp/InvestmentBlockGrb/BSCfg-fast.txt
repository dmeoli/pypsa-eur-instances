#
# The speed-oriented sibling of BSCfg.txt: same Solver, same relaxation, but
# the presolve is left on and the numerical focus at its default. BSCfg.txt
# trades those two for a stable optimal vertex, which the linearization of the
# InvestmentFunction rests on; this file trades the stability back for time,
# and asks for run-to-run comparability from a fixed Seed instead.
#
# Which of the two to use is a property of the run, not of the instance: take
# BSCfg.txt when the linearization must be reproducible across solvers, and
# this one when the number that matters is the wall clock. On the monolithic
# TwoStageStochasticBlock LP the two settings are worth 2.61 work units
# against 70.05, so the difference is not a detail.
#
#   Antonio Frangioni
#   Donato Meoli
#
